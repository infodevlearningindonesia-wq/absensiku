4. STRUKTUR REST API AKTIF PADA URL:
--------------------------------------------------------------------------------
A. Autentikasi:
   - POST /api/register
     Mendaftarkan user baru (name, email, password).
     Syarat password: Wajib huruf besar, huruf kecil, dan angka/simbol.
   
   - POST /api/login
     Login user untuk mendapatkan Bearer Token (email, password).
   
   - GET /api/profile
     Mengambil data profil pengguna yang sedang login.
     Header: Authorization: Bearer <token>

B. Presensi / Absensi:
   - POST /api/absen/check-in
     Absen masuk.
     Body: check_in_lat, check_in_lng, check_in_address
     Header: Authorization: Bearer <token>

   - POST /api/absen/check-out
     Absen keluar/pulang.
     Body: check_out_lat, check_out_lng, check_out_address
     Header: Authorization: Bearer <token>

   - GET /api/absen/history
     Mengambil daftar riwayat absensi pengguna.
     Header: Authorization: Bearer <token>

   - DELETE /api/absen/{id}
     Menghapus data absensi berdasarkan ID absensi.
     Header: Authorization: Bearer <token>
